# PAYDAY-2-Continent-Blender-Importer

## WARNING

I am not a programmer, practically the whole script is generated by Claude, but has been rigorously trialed and tested by me to ensure the highest quality when importing maps, there will be a few visual bugs that I do not know of yet and does require very specific ways to use it. 

Now that disclaimer has been said, here is a description of requirements to use this add-on and a small guide of how to import your .json file.


## Requirements

- Extracted PAYDAY 2 Assets (32 or 64 Bit)  
  - For 32 Bit branch asset extraction, use [Diesel Bundle Viewer](https://modworkshop.net/mod/27741) and a up-to date [Hashlist](https://github.com/Luffyyy/PAYDAY-2-Hashlist)
   - You will also need to make every .texture extension converted to .dds, if you are on Windows 10/11 use this Powershell script with a command prompt in your root folder with your extracted assets
 
**Get-ChildItem -Recurse -Filter *.texture | ForEach-Object { Rename-Item $_.FullName ($_.FullName -replace '\.texture$', '.dds') }**



  - For 64 Bit branch asset extraction, use [Diesel Crate Browser](https://modworkshop.net/mod/57750) (Auto converts every .texture to .dds)
- The [PAYDAY 2 Model Tool](https://github.com/kythyria/payday2-model-tool) (This version will only work for 32 Bit assets)
   - For 64 Bit branch Model Tool, use the [RAID Model Tool](https://github.com/diesel-modding/raid-model-tool) (Fair warning, tangents are completely messed up on this branch)

## Blender Requirements
- The [Diesel Model Tool Wrapper](https://gitlab.com/cpone/io_scene_dieselmodeltoolwrapper)
-  [Diesel Animation Importer](https://gitlab.com/cpone/io_scene_dieselanim) (Optional, this add-on does not currently support animation imports)

## PAYDAY 2 Requirements

- [SuperBLT](https://superblt.znix.xyz/)
- [Beardlib](https://modworkshop.net/mod/14924)
- [Beardlib Editor](https://modworkshop.net/mod/16837)

## In-Game Requirements

  We will be using Beardlib Editor to convert our .continent files to .json files, to properly use it:

  ScriptData > "Your Extracted Assets Folder Location" > levels/narratives/YourContractor/YourHeist/world/world.continent (You can safely ignore any .mission files and the other files in the root directory)
  - Convert from Binary to json
    - (Some levels may use multiple continents for separating props and architecture, so you may need to convert more .world files if need be)
    - In Blender, go to File > Import > PAYDAY 2 Level (.json) (Adjust import settings to your liking and preference of what you want)
    - Import your .json file
   

- Another method you can do to if you are lazy:
   - Levels > New... > Cloned Map
   - Then choose whatever heist you want to clone (Then go to your Maps folder and go to your folder name of what you called the cloned map > levels > YourID > world > world.continent)
     (If you are doing this because your map has multiple continent files you want to combine into one)
   - Go into your freshly cloned heist
   - Mix all your other continent files units into the world continent and then save your changes
   - Repeat previous steps of converting .continent to .json
